# Reporting a security issue

**English** · [Español](SECURITY.es.md)

Report privately through [GitHub Security Advisories](https://github.com/cbatista96/FluxBrowser/security/advisories/new). Include the version, active engine (WebView2 or CEF), impact and steps to reproduce. Remove personal data from attachments.

Report ordinary bugs in [GitHub Issues](https://github.com/cbatista96/FluxBrowser/issues).
