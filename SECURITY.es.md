# Informar de un problema de seguridad

[English](SECURITY.md) · **Español**

Envía el informe de forma privada mediante [GitHub Security Advisories](https://github.com/cbatista96/FluxBrowser/security/advisories/new). Incluye la versión, el motor activo (WebView2 o CEF), el impacto y los pasos para reproducirlo. Elimina datos personales de los archivos adjuntos.

Los fallos de funcionamiento se registran en [Issues](https://github.com/cbatista96/FluxBrowser/issues).
